1. **MaNGA survey overview** — Bundy, K., et al. (2015), “Overview of the SDSS-IV MaNGA Survey: Mapping Nearby Galaxies at Apache Point Observatory,” *The Astrophysical Journal*, 798, 7. [https://doi.org/10.1088/0004-637X/798/1/7](https://doi.org/10.1088/0004-637X/798/1/7).  
   Survey design and scientific motivation for spatially resolved spectroscopy of nearby galaxies.

2. **MaNGA Data Analysis Pipeline overview** — Westfall, K. B., et al. (2019), “The Data Analysis Pipeline for the SDSS-IV MaNGA IFU Galaxy Survey: Overview,” *The Astronomical Journal*, 158, 231. [https://doi.org/10.3847/1538-3881/ab44a2](https://doi.org/10.3847/1538-3881/ab44a2).  
   Cite when using MaNGA DAP products or discussing their measurements and quality assessments.

3. **MaNGA Data Analysis Pipeline emission-line modeling** — Belfiore, F., et al. (2019), “The Data Analysis Pipeline for the SDSS-IV MaNGA IFU Galaxy Survey: Emission-Line Modeling,” *The Astronomical Journal*, 158, 160.  
   See the SDSS DAP citation guidance: [MaNGA DAP documentation](https://sdss-mangadap.readthedocs.io/). Verify whether this paper is relevant to the specific products used before retaining this entry.

[https://doi.org/10.1093/mnras/stw3020](https://doi.org/10.1093/mnras/stw3020).

[https://doi.org/10.3847/1538-4365/ac4414](https://doi.org/10.3847/1538-4365/ac4414).  
   Cite only if the project uses DR17 products; otherwise cite the actual release used.

6. **MaNGA Data Reduction Pipeline** — Law, D. R., et al. (2016), “The Data Reduction Pipeline for the SDSS-IV MaNGA IFU Galaxy Survey,” *The Astronomical Journal*, 152, 83. [https://doi.org/10.3847/0004-6256/152/4/83](https://doi.org/10.3847/0004-6256/152/4/83).
