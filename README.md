# MaNGA Stellar Kinematics of a Candidate SMBH-Binary Host Galaxy

Research repository for an IFU-based study of the stellar kinematics and projected structure of a candidate supermassive black hole (SMBH) binary host galaxy using Sloan Digital Sky Survey (SDSS-IV) MaNGA data.

> **Project status:** Active analysis. This repository documents the workflow represented by the notebooks currently listed in the repository. Scientific interpretations and numerical results should be treated as provisional until the corresponding notebook outputs, quality checks, and uncertainty analyses have been reviewed.

## Research overview

Integral-field spectroscopy provides spatially resolved spectra across a galaxy, enabling measurements of stellar line-of-sight velocity and velocity dispersion over the observed field. This project uses MaNGA data products to inspect the target observation, extract and validate stellar-kinematic measurements, relate the measurements to the galaxy's projected geometry, and examine spatially resolved and radial behaviour.

The project is an analysis of a **candidate** SMBH-binary host. Stellar-kinematic structure alone does not establish the presence of a binary SMBH; any such interpretation requires additional evidence and careful consideration of alternative dynamical and observational explanations.

## Research objectives

1. Document and inspect the MaNGA observation and its FITS metadata.
2. Extract and examine the available stellar-kinematic measurements.
3. establish the spatial coordinate system and projected galaxy geometry using WCS information.
4. Quantify stellar-kinematic properties and assess their uncertainties and robustness.
5. Validate the measurements using independent checks, including spatially resolved and radial analyses.
6. Relate the kinematic measurements to photometric/projected geometry without overstating what the data can establish about an SMBH binary.
7. Make the analysis reproducible through documented software dependencies, data provenance, and notebook execution order.

## Installation

Use a clean Python environment where possible. The dependency list is maintained in [`requirements.txt`](requirements.txt).

```powershell
# From the repository root on Windows
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Then launch Jupyter:

```powershell
python -m pip install jupyterlab
jupyter lab
```

If JupyterLab is already included in `requirements.txt`, the separate install command is unnecessary. Record the tested Python version and package versions after confirming the environment actually runs the notebooks.

## Reproducibility

- Run notebooks in the documented order in [docs/NOTEBOOK_INDEX.md](docs/NOTEBOOK_INDEX.md).
- Obtain the required MaNGA FITS products from the official SDSS archive; do not assume raw data are included here.
- Record the SDSS data release, DRP version, DAP version/DAPTYPE, file names, retrieval date, and checksums.
- Keep raw data separate from derived products.
- Preserve the notebook outputs used to support any reported numerical result, or provide a script that regenerates the figures and tables.
- Document all masks, quality flags, binning choices, instrumental-resolution corrections, adopted geometry, and uncertainty calculations.
- Set random seeds where stochastic methods are used.
- Do not present a result as independently validated unless the validation notebook demonstrates the check.
- Review notebook execution from a fresh kernel before tagging a release.
